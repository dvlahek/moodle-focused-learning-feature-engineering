# Suggested data and code availability statement

The implementation code, privacy-safe synthetic example data, and instructions required to execute the complete analysis workflow are provided as supplementary material. The original student-level Moodle logs and assessment records cannot be made publicly available because they contain protected educational data and are subject to student-privacy and institutional restrictions. The included synthetic data reproduce the required input structure solely for code execution and inspection; they contain no real participant records and do not reproduce the numerical findings reported in the manuscript.

## Scope of the shared material

The package includes executable code for feature engineering, model evaluation, cross-cohort validation, environmental permutation testing, feature importance, and figure generation. Exact reproduction of the manuscript's numerical results requires authorized access to the protected original data.
